1.2 정보구조 원칙
기존 홈페이지는 유지한다. 새로운 진입 링크 “한국 유학·유학생 지원 / Du học Hàn Quốc”만 신설한다.
권장 경로: /study-korea. 언어는 현 사이트 다국어 인프라를 재사용하고, 지원하지 않으면 /study-korea?lang=vi 및 ?lang=ko 형태로 적용한다.
신규 페이지의 독립 헤더: 로고(기존 홈페이지로 이동) · 지원서비스 · 진행절차 · 부산 생활 · 협력제안 · [유학 상담 신청].
서비스 운영 주체는 “주식회사 브이알메디투어앤홈”. “VR STUDENT KOREA”는 제품/서비스명으로만 표기한다.

360~430px 모바일을 1차 디자인 기준으로 설정. 버튼 전체폭, 본문 1열, CTA 44px 이상 권장.
섹션간 고정 대형 광고·팝업을 금지. 언어전환과 문의 CTA가 화면 상단에 명확히 보이게 배치.
학생의 주 입력 수단으로 휴대전화·Zalo 연락정보를 고려하고 키보드 유형과 국가번호를 자동 보조한다.

실패: 필드별 오류 표시, 재시도 가능, 중복 제출 방지. 429 과다 요청·500 서버 오류는 별도 안내.
만 14세 미만 등 미성년자는 연령·법정대리인 동의 요건을 법무 검토한 후 신청 범위를 확정한다. 초기에 연령·동의 관리가 어렵다면 해당 접수를 제한한다.

7.1 기술·API 계약(프레임워크 비종속)
예시 API: POST /api/study-leads, GET /api/admin/study-leads, PATCH /api/admin/study-leads/{id}, GET /api/study-content. URL은 제안이며 기존 서버 라우팅과 충돌하지 않게 개발사가 확정한다.
서버 검증: 요청 크기 제한, 필수 동의, 국가번호·이메일 형식, 입력 길이, CSRF/CORS/봇 차단, 서버측 권한검사, rate limit, 5xx 장애 알림. 원문 서류나 신분증 등 민감한 첨부는 MVP에서 불허한다.
