## 판정과 충족률

“구현 완료”는 해당 FR의 코드와 현재 범위의 인수 테스트가 있는 경우, “부분 구현”은 UI/검증/모델은 있으나 영구 저장·정책 승인 등 필수 조건이 남은 경우, “미구현”은 해당 기능이 없는 경우다. 실제 Netlify/Auth/DB 환경이 없는 검증은 별도 미검증으로 표시한다.

**엄격한 FR 단위 완료: 3/12 = 25%. P0만: 3/8 = 37.5%.** 부분 구현을 50% 등으로 가산하지 않았다. 화면 작성률·코드 분량이 아니라 각 인수기준 전체 충족 여부를 기준으로 계산했다. **운영 오픈은 NO-GO**: 실제 저장/관리자 인증/확정된 개인정보 정책이 없기 때문이다.

## 관리자·데이터 모델

모의 UI `/dev-tools/study-korea-admin/`는 공개 dist에서 제외되고 실제 개인정보를 사용하지 않는다. 역할 선택은 로그인/인증이 아니다.

- 상태: NEW → CONTACT_ATTEMPTED → CONTACTED → CONSULTING → QUALIFIED → CLOSED. 진행 상태에서 CLOSED 허용, CLOSED 후 재개는 별도 규칙 승인 전 금지.
- 역할: ADMIN 전체 모의 리드·배정, COUNSELOR 본인 배정 학생, B2B_MANAGER 본인 배정 파트너, CONTENT_EDITOR 리드 열람 불가. 다운로드·삭제·권한 변경·콘텐츠 편집 API는 제공하지 않음.
- 버전 충돌 검사, 배정 역할/활성 검사, 변경 actor/time 표시. 실제 감사기록은 아직 저장하지 않음.
- `docs/study-korea-data-model.sql`: Lead, ConsentRecord, UniversityContent, PartnerRecord, AdminAudit, 담당자/상담메모/알림 outbox 초안. **미실행**. 기본 RLS 거절, 실제 Auth 검증 정책/권한 부여 없음.
- 동의는 필수 처리와 선택 마케팅의 목적/버전/시각을 분리하고 마케팅 철회 시각 필드 마련. 운영 파기/철회 API와 예약 작업은 미구현.
- 동일 submission_id + 동일 canonical intent HMAC는 기존 접수번호, 다른 내용은 409 계약. 언어/시각은 canonical intent에서 제외. 브라우저는 언어 변경 후에도 동일 입력의 재시도 ID 유지. 새로고침/여러 탭까지의 중복 방지는 실제 DB/제출토큰 구현 필요.
- 저장+동의+outbox 트랜잭션 커밋 이후만 성공; STUDENT_TEAM/PARTNER_TEAM 알림 분리. 관리자 알림에는 고객 본문을 넣지 않음. 수신기/트랜잭션/발송기는 아직 미연결.
- delete_after는 승인된 보유정책으로만 계산, 임의 보유기간 없음. 문의/동의/메모/outbox 삭제와 감사기록 별도 보유, 백업 만료·복원 후 재삭제·본인확인 필요.

## 환경변수 추가 및 활성화 금지

이전 `STUDY_KOREA_ENABLED`, `RECEIVER_VERIFIED`, `RECEIVER_URL`, `RECEIVER_TOKEN`, `SITE_ORIGIN`, `POLICY_VERSION`, `POLICY_KO`, `POLICY_VI`에 더해:

- `STUDY_KOREA_INTAKE_SCOPE_APPROVED=true`: 미성년/보호자 접수범위를 법무 검토한 뒤에만 설정. 없으면 GET 비활성/POST 503.
- 선택 마케팅은 `STUDY_KOREA_MARKETING_VERSION`, `STUDY_KOREA_MARKETING_KO`, `STUDY_KOREA_MARKETING_VI`가 모두 있어야 표시된 목적/기간에 동의 가능. 세 값 없을 때 false로 상담 가능, true 제출은 거절.
- 어떤 변수도 이번 작업에서 운영에 설정/활성화하지 않았다. 테스트 프로세스의 가짜 값만 사용했다.

## 공개 산출물·기존 기능 보호

기존 개선의 `publish="dist"`/명시적 허용목록 유지. 신규 공개 검증/콘텐츠 파일 3개를 목록에 추가해 **364개** 공개 파일 생성. PRD 본문/SQL/문서/테스트/dev-tools/서버 소스/비밀 파일은 제외. 빌드는 알려진 비밀키 패턴/경로 이탈/심볼릭 링크를 거절하지만 모든 비밀정보를 탐지하는 보안감사를 대신하지 않는다.

기존 의료/AI/통역/관광/K뷰티/상점/한국어/옴니볼 소스는 수정하지 않았다. 홈페이지 공용 언어 데이터의 새 유학 메뉴 한국어 문구만 변경. 유학 접수 함수와 데이터 schema는 의료 문의 흐름을 호출하지 않는다.
