01 / ABOUT THE PRODUCT

제품을 먼저,
차근차근 살펴보세요.

옴니볼 스키는 보행기 다리에 부착하는 이동·지지 보조 구성품입니다. 중앙 볼과 스프링, 바닥 패드를 결합하여 가볍게 밀 때는 볼이 구르고, 하중을 실으면 패드가 바닥에 닿도록 설계하는 개념입니다.

위 설명은 제공된 PRD의 설계 개념이며, 실제 제품 동작과의 대조가 필요합니다. 도입을 검토하고 계신가요? 사용 목적과 환경을 알려 주시면 제품 구성, 사용 조건과 협력 가능 여부를 문의하실 수 있습니다.

02 / MOVEMENT PRINCIPLE

이동 · 지지 · 복귀

중앙 볼 · 스프링 · 바닥 패드의 설계 개념.
실제 제품의 동작과 성능을 보장하는 설명은 아닙니다.

01

이동 Movement

하중이 적을 때 중앙 볼이 구르며 이동하고, 바닥 패드는 바닥에서 떨어져 있도록 설계된 상태입니다.

02

지지 Support

하중을 실으면 스프링이 압축되고 바닥 패드가 접지하여 지지하도록 설계된 상태입니다.

03

복귀 Return

하중을 줄이면 스프링이 복원되어 중앙 볼이 다시 노출되고 이동 상태로 돌아가도록 설계된 개념입니다.

제공된 이동·지지·복귀 개념 이미지입니다. 실제 외형·체결 구조·작동 하중·복귀 동작은 제조 자료와 시험 결과로 확인해야 합니다.

03 / GETTING STARTED

사용 흐름 개념.

검증된 사용설명서를 대신하지 않습니다. 장착과 사용 전 제조자의 확인이 필요합니다.

  1. 01 / FIT

    끼워 장착

    보행기 다리에 부착하는 개념입니다. 다리 규격, 장착 위치·수량, 체결 및 고정 확인 방법은 문의 시 확인해 주세요.

  2. 02 / MOVE

    가볍게 밀기

    하중이 적을 때 중앙 볼을 이용해 이동하도록 설계된 개념입니다.

  3. 03 / SUPPORT

    눌러 지지

    하중에 반응하여 패드가 바닥에 접촉하도록 설계된 개념입니다. 지지 성능은 별도 검증이 필요합니다.

사용 전 점검 사항, 허용 바닥 환경과 사용 제한을 반드시 확인해 주세요. 낙상 방지나 완벽한 제동을 보장하지 않습니다.

05 / QUESTIONS & ANSWERS

자주 묻는 질문.

어떤 보행기에 장착할 수 있나요?

보행기 모델명과 다리 규격을 알려 주시면 호환 여부를 문의하실 수 있습니다. 검증된 호환 목록은 아직 제공되지 않으며, 모든 보행기에 장착 가능하다고 단정하지 않습니다.

설치 시 어떤 확인이 필요한가요?

장착 위치와 수량, 체결 방식, 고정 확인 방법과 사용 전 점검 사항을 제조자에게 확인해야 합니다. 위의 사용 흐름은 개념 안내입니다.

이동 상태와 지지 상태는 어떻게 달라지나요?

설계 개념상 하중이 적을 때는 중앙 볼이 구르고, 하중을 실으면 스프링이 압축되어 패드가 바닥에 접촉합니다. 실제 작동 하중과 지지 성능은 별도 확인이 필요합니다.

사용할 수 있는 바닥 환경은 무엇인가요?

바닥 재질, 경사와 사용 장소를 알려 주세요. 허용 바닥 환경과 사용 제한은 검증 자료 확인 후 안내해야 합니다.

구매 또는 기관 도입이 가능한가요?

구매·도입 가능 여부, 가격과 공급 일정은 문의 시 확인해 주세요. 판매 중이거나 즉시 공급 가능하다는 의미는 아닙니다.

유통·제조 협력은 어떻게 문의하나요?

아래 이메일 협력 문의 버튼을 이용해 기관 소개, 협력 목적과 검토 일정을 알려 주세요. 온라인 문의 양식은 현재 접수하지 않습니다.

특허 등록 제품인가요?

현재 제공된 자료로는 출원·등록 여부가 확인되지 않았습니다. 필요한 경우 권리자, 출원·등록번호와 공식 확인 자료를 요청해 주세요.
